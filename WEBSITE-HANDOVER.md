# Kracht 4x4 website

Four static pages: index.html, about-contact.html, suppliers.html and completed-jobs.html. No package installation or build service is required. Serve the repository using any static web host.

Shared styling: assets/css/style.css. Shared interactions: main.js. Optimised website photographs and logos: assets/site/. Original supplied assets are preserved in assets/Images/.

The WhatsApp form opens a prepared message; it does not send automatically, store submissions or require a form subscription. Phone, email, map directions, Facebook and Instagram are direct links.
